# Contributing

Thanks for your interest in REVYTECH projects.

- Open an issue describing the bug or proposal before large changes.
- Fork, branch from the default branch, and keep pull requests focused.
- Follow the existing style of the repository and include tests where practical.
- By contributing you agree your work is licensed under the repository's license.
